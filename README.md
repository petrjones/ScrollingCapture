# PJSoft Scrolling Capture

Portable Windows utility for capturing scrolling content, combining screenshots, and exporting to PNG or PDF.

Available in English, Czech (Rolovací výstřižek), and Spanish.

## Download

[Download the latest release](https://github.com/petrjones/ScrollingCapture/releases/latest)

Download the ZIP from the release's Assets section, extract it, and run the EXE. No installation is required.

## Main features

- Capture vertically scrolling content and merge overlapping screenshots.
- Collect screenshots manually and combine them vertically or horizontally.
- Reorder screenshots using buttons or drag and drop.
- Configure a keyboard shortcut for adding screenshots.
- Export to PNG or PDF, including multi-page A4 output.
- Create searchable PDFs using local Windows OCR.
- Read text items from supported accessible menus.
- Number menu items starting at a selected position.
- Clear the loaded menu without deleting saved files.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- .NET Framework 4.8.
- Windows OCR language support for text recognition in screenshots.

Scrolling capture and menu reading depend on the target application. Custom or virtualized controls may not be supported. Always check the captured result.

## Languages

English, Czech and Spanish. Select a language in the application and restart to apply it.

## Settings

Language and contribution preferences are stored in:
%LOCALAPPDATA%\PJSoft\ScrollingCapture\settings.json

The capture shortcut is stored in ScrollingCapture.shortcut.txt beside the executable.
